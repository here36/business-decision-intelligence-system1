# 📊 Business Decision Intelligence System

An end-to-end Data Analytics project that transforms raw retail sales data into meaningful business insights using **Excel, MySQL, Python, Pandas, Matplotlib, and Streamlit**.

The project demonstrates the complete analytics workflow—from data cleaning and SQL analysis to interactive dashboard development and business decision support.


## ✨ Features

* 📈 Interactive Streamlit Dashboard
* 📊 KPI Cards (Revenue, Profit, Orders, Customers)
* 📅 Monthly Revenue Trend Analysis
* 📦 Sales by Product Category
* 🌍 Profit Analysis by Region
* 👥 Sales Analysis by Customer Segment
* 🏆 Top 10 Best-Selling Products
* 📉 Top 10 Loss-Making Products
* 💡 Automated Business Insights
* 🔍 Interactive Region & Category Filters
* 📥 Download Filtered Dataset as CSV

## 🛠️ Tech Stack

* **Excel** – Data Cleaning & Initial Analysis
* **MySQL** – SQL Queries & Business Analysis
* **Python** – Data Processing
* **Pandas** – Data Manipulation
* **Matplotlib** – Data Visualization
* **Streamlit** – Interactive Dashboard
* **Git & GitHub** – Version Control

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/here36/business-decision-intelligence-system.git
```

Navigate to the project folder:

```bash
cd business-decision-intelligence-system
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit dashboard:

```bash
streamlit run dashboard/app.py
```

## 📈 Business Insights

This dashboard helps answer important business questions such as:

* Which product category generates the highest sales?
* Which region is the most profitable?
* Which customer segment contributes the most revenue?
* Which products are causing losses?
* How do monthly sales change over time?

The interactive filters allow users to analyze specific regions and product categories for better decision-making.
